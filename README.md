# Java Coding Practice

This repository contains organized Java code examples for various topics including data structures, algorithms, design patterns, multithreading, and more. Each folder groups related files with refactored code and comments for easy reference and interview preparation.

## Structure Overview
- **Arrays**: Array operations, utilities, and problems.
- **Basics**: Basic exercises and games.
- **BitManipulation**: Bit-level operations.
- **DateTime**: Date-Time API examples.
- **DesignPatterns**: Design pattern implementations.
- **Enums**: Enum testing.
- **Exceptions**: Exception handling.
- **Executors**: Executor framework.
- **FileIO**: File reading/writing.
- **Functional**: Functional interfaces and references.
- **Interviews**: Interview-specific code.
- **LeetCode**: LeetCode solutions.
- **Maps**: Map usage.
- **MultiThreading**: Threading basics.
- **OOP**: OOP concepts like classes, final, static.
- **Optionals**: Optional class examples.
- **Queue**: Queue testing.
- **Recursion**: Recursive algorithms.
- **Searching**: Search algorithms.
- **Sets**: Set operations.
- **Sorting**: Sorting algorithms.
- **Streams**: Stream API examples.
- **Strings**: String manipulations.
- **ThreadingChallenge**: Threading challenges.

For quick reference, navigate to specific folders. Files include comments for recall.
